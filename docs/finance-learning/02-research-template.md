# 投资研究备忘录模板

复制本文件的结构到 `research/` 中。一个备忘录只研究一个主题、一个产品或一家公司，避免把多个结论混在一起。

## 1. 基本信息

- 研究对象：
- 类型：公司 / 基金 / ETF / 债券 / 指数 / 宏观主题 / 其他
- 代码或唯一标识：
- 研究日期：
- 数据截至日期：
- 研究目的：了解 / 纳入观察 / 计划投入 / 复盘已有持仓

## 2. 一句话理解

用不超过三句话说明：它靠什么产生收益，主要暴露于什么风险，适合什么场景。

## 3. 已确认事实

只写可以回到来源核验的内容：

- 业务或指数规则：
- 收益来源：
- 费用、税费和交易摩擦：
- 流动性、申赎和限制：
- 近年关键变化：

每条事实尽量附上来源、发布日期、查询日期和数据口径。

## 4. 我的推断

- 可能的长期驱动因素：
- 可能的竞争优势或结构性特征：
- 对利率、经济周期、汇率或政策的敏感性：
- 与现有资产的相关性或重复暴露：

明确标注这是推断，不要写成事实。

## 5. 风险清单

- 永久性损失风险：
- 高波动和回撤风险：
- 流动性风险：
- 信用或对手方风险：
- 汇率风险：
- 政策、监管或税务风险：
- 信息披露和治理风险：
- 自己无法理解的风险：

## 6. 估值或价格判断

只有在理解数据口径后再记录：

- 使用的指标和计算口径：
- 历史区间或可比对象：
- 关键假设：
- 哪些假设一旦改变，结论会失效：
- 为什么不能仅凭一个指标下结论：

## 7. 结论与行动

- 当前结论：继续学习 / 观察 / 小额验证 / 按计划投入 / 暂不考虑
- 结论成立的前提：
- 需要补充的资料：
- 复核日期：
- 触发重新研究的事件：

## 8. 来源质量检查

- [ ] 关键事实来自原始或官方资料
- [ ] 数据有明确日期和口径
- [ ] 没有把预测当成事实
- [ ] 至少记录一个支持观点和一个反对观点
- [ ] 没有只因为过去上涨就推断未来上涨
- [ ] 没有把模型、媒体或社交平台观点当作独立证据
