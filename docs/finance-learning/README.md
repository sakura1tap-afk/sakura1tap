# 金融与长期投资学习库

这个文件夹用于持续积累金融知识、投资研究方法和可复用的分析技能，服务于“每月固定投入、为未来建立基础”的长期计划。

## 定位

- 这是学习与决策记录库，不是荐股清单，也不是自动交易系统。
- 任何涉及价格、政策、公司经营、产品规则和税务的信息，都要在使用前重新核验来源与日期。
- 记录“为什么做决定”，比记录“这次赚了多少”更重要。
- 默认优先考虑长期、分散、低成本、可理解和能坚持的方案。

## 推荐工作流

1. 先学习概念，再研究具体产品；不要从“今天买什么”开始。
2. 先写研究假设和风险，再看观点是否被数据支持。
3. 同花顺只作为查看行情、公告和账户操作的工具，不能替代独立判断。
4. 每月固定日期记录投入、持仓变化、现金流和情绪状态。
5. 每季度复盘一次规则是否仍然适合自己，避免因为短期涨跌频繁改计划。

## 使用边界

- 不在文档中保存账号、密码、验证码、交易凭证、API 密钥或完整账户截图。
- 不把未经核验的社交媒体内容当作事实或唯一依据。
- 不因单条新闻、短期涨跌、群聊观点或模型输出直接下单。
- 需要结合个人收入、负债、现金流、风险承受能力和所在地规则时，先补齐个人信息并进行独立核验。
