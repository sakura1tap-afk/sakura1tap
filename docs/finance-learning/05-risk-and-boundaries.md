# 风险控制与边界

金融学习的第一目标是避免不可逆的错误，其次才是提高收益可能性。

## 个人风险边界

- 不借钱投资，不用影响基本生活的钱承担高波动风险。
- 不把应急金、短期确定用途资金和长期投资混在一起。
- 不因模型、媒体、群聊或单条消息直接下单。
- 不使用无法解释收益来源和最大风险的产品。
- 不把历史收益、模拟盘结果或短期胜率当作未来保证。
- 不在笔记中保存敏感账户信息、完整交易凭证或可用于登录的内容。

## 信息安全边界

- 只记录脱敏后的金额、比例和类别；必要时使用区间而非精确余额。
- 任何外部链接、脚本、数据文件或代码都先检查来源和用途。
- 不执行来源不明的“自动选股”“自动交易”脚本。
- 不把同花顺账号、验证码、Cookie、导出文件或个人身份证明材料提交给模型或第三方工具。

## 需要人工确认的事情

以下事项不能仅靠这套学习库自动决定：

- 具体产品是否适合个人情况
- 税务、法律、监管和跨境规则
- 借贷、杠杆、期权、期货、融资融券等高风险业务
- 账户权限、转账、下单、赎回和任何不可逆操作

模型可以帮助整理资料、检查逻辑、生成问题清单和复盘模板，但最终操作必须由本人在核验最新信息后决定。
