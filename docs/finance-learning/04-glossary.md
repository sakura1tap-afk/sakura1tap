# 金融与投资术语表

先记录自己的理解，再补充正式定义。遇到不同来源口径不一致时，保留口径说明。

| 术语 | 当前理解 | 需要注意 |
| --- | --- | --- |
| 复利 | 收益继续参与后续收益形成累积效果 | 实际收益会受到亏损、费用、税费和投入时间影响 |
| 通货膨胀 | 货币购买力随时间下降 | 需要区分名义收益和实际收益 |
| 波动率 | 价格或收益变动的程度 | 波动不等于永久损失，但会影响持有体验 |
| 回撤 | 从历史高点到之后低点的下降幅度 | 要关注最大回撤、恢复时间和自身承受能力 |
| 流动性 | 资产变现的速度和成本 | 高流动性不代表低风险 |
| 分散化 | 把风险分布到不同资产或风险来源 | 持有很多同类资产不一定真正分散 |
| 再平衡 | 把组合拉回目标配置 | 需要提前写触发条件和交易成本边界 |
| 费率 | 产品或交易持续产生的成本 | 小比例长期累积也可能影响结果 |
| 跟踪误差 | 产品表现偏离目标指数或基准的程度 | 要结合复制方式、费用和分红处理理解 |
| 自由现金流 | 经营活动产生现金扣除必要资本支出后的余量 | 口径和一次性项目需要仔细核验 |
| ROE | 净利润相对股东权益的回报指标 | 可能受高杠杆、回购和会计口径影响 |
| 安全边际 | 给估计误差和不确定性留下缓冲 | 不是保证不亏损 |
