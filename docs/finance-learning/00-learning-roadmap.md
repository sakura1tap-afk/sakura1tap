# 学习路线

目标不是短期预测市场，而是建立能够长期执行、复核和纠错的能力。

## 阶段一：金融基础

- 货币时间价值、复利、通货膨胀、实际收益率
- 资产、负债、收入、支出、现金流和净资产
- 风险、波动、回撤、流动性、信用风险和通胀风险
- 名义收益、实际收益、税费、费率和摩擦成本

**完成标准**：能用自己的话解释一个金融产品如何产生收益、可能如何亏损，以及钱何时可以取出。

## 阶段二：投资工具

- 股票、债券、货币基金、指数基金、ETF、REITs 和现金类资产
- 主动管理与被动投资的差异
- 基金净值、跟踪误差、费率、规模、流动性和折溢价
- 交易规则、申赎规则、分红、税务和汇率影响

**完成标准**：能为每类工具写出“收益来源、主要风险、适用场景、不适用场景”。

## 阶段三：组合与长期计划

- 目标、期限、流动性需求与风险承受能力
- 分散化、相关性、回撤、再平衡和资产配置
- 固定投入、估值投入、现金储备和应急金
- 投资纪律、行为偏差和下跌期的应对规则

**完成标准**：能在不依赖短期预测的前提下，写出一套可执行的月度流程。

## 阶段四：研究能力

- 读财务报表：利润表、资产负债表、现金流量表
- 收入质量、利润率、ROE、ROIC、自由现金流和负债结构
- 商业模式、竞争优势、行业周期、治理和管理层
- 估值的基本思想：市盈率、市净率、现金流估值及其局限
- 宏观变量：利率、通胀、就业、汇率和政策传导

**完成标准**：能写出一页研究备忘录，并清楚区分事实、推断和不确定性。

## 阶段五：同花顺与信息工具

- 查找公告、定期报告、指数规则和基金资料
- 建立来源优先级：监管/交易所/发行人原始资料 > 官方产品文件 > 权威媒体 > 社区观点
- 记录查询日期、数据口径、单位、复权方式和时间范围
- 用表格或脚本做简单的历史记录与复盘，而不是追逐盘中噪音

**完成标准**：任何关键结论都能回到来源，并说明数据是否可能已经过时。
