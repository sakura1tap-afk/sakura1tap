# 每月固定投入框架

这是一个“先建立规则、再执行投入”的框架，不预设具体金额、产品或收益率。具体方案必须结合个人现金流、负债、应急储备、投资期限和适当性要求。

## 投入前检查

每月投入前确认：

- 基本生活费和近期确定支出已经安排好。
- 高成本债务和逾期风险没有被忽略。
- 应急资金目标正在建立或已经达到可接受水平。
- 本月投入金额即使短期大幅下跌，也不会影响生活和必要支出。
- 没有因为追涨、恐慌、群聊消息或“错过机会”的焦虑临时改变计划。

如果任一项不满足，优先处理现金流和风险，而不是强行完成投资额度。

## 月度流程

1. **记录**：填写本月可投入金额、现金储备、负债变化和重大支出。
2. **核验**：确认计划中的产品名称、代码、费率、交易规则和最新资料。
3. **执行**：按照预先写好的资产配置和金额规则操作，避免盘中临时判断。
4. **留痕**：记录执行日期、成交/申购金额、费用、价格或净值口径。
5. **冷静期**：除非发生预先定义的重大变化，不因一个月的涨跌修改长期规则。
6. **复盘**：月底只复盘流程是否合规，不把短期盈亏直接当作能力证明。

## 配置规则应写清楚

在做任何长期投入前，单独写下：

- 目标：这笔钱服务于什么未来目标。
- 期限：预计何时使用，是否可能提前使用。
- 流动性：需要多久能够变现，能接受多大折价或波动。
- 可承受损失：出现怎样的回撤仍能按计划生活和继续执行。
- 资产范围：只投自己能解释清楚的工具。
- 单一资产上限：避免单一公司、行业、地区或主题过度集中。
- 再平衡规则：按时间或偏离幅度触发，而不是按情绪触发。
- 停止条件：哪些事实变化会让原先的投资理由失效。

## 月度记录模板

建议复制 `templates/monthly-record.md`，命名为 `monthly-records/YYYY-MM.md`。

至少记录：

- 本月投入金额与资金来源
- 现金储备和负债变化
- 各资产类别的目标比例与实际比例
- 本月执行动作及费用
- 关键资料核验日期
- 当时的主要情绪和可能的行为偏差
- 下月是否继续、暂停或调整，以及调整依据

## 重要提醒

固定投入能帮助减少择时依赖，但不能消除亏损风险，也不能保证收益。任何“稳定收益”“保本高收益”或“只涨不跌”的表述，都应当先当作需要核验的营销信息。
