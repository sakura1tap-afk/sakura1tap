# 技能目录

技能的目标是提升判断质量，不是制造“预测市场”的错觉。学习完成要有笔记、计算、研究备忘录或复盘记录作为证据。

## 信息与研究技能

- **来源检索**：找到公告、定期报告、基金文件和指数规则。
- **来源核验**：检查发布日期、数据口径、是否断章取义、是否已经过时。
- **事实与观点分离**：把原文事实、自己的推断和不确定性分栏记录。
- **信息摘要**：把长资料压缩为可复核的关键结论。

## 财务分析技能

- **三大报表阅读**：识别收入、利润、资产、负债和现金流之间的关系。
- **质量分析**：观察利润是否转化为现金，增长是否依赖高杠杆或一次性项目。
- **指标理解**：理解 ROE、ROIC、毛利率、净利率、自由现金流和负债率的局限。
- **估值基础**：理解估值假设、敏感性和安全边际，不把单一倍数当答案。

## 组合与风险技能

- **资产配置**：根据目标、期限、流动性和承受能力安排资产类别。
- **分散与相关性**：识别看似不同、实际同涨同跌的重复暴露。
- **回撤管理**：提前写好下跌期的行动规则，避免临场情绪决策。
- **再平衡**：按预先定义的时间或偏离范围调整，而不是追逐近期表现。
- **情景分析**：考虑利率上升、经济衰退、流动性收缩和个人收入中断等场景。

## 执行与复盘技能

- **成本意识**：关注费率、佣金、价差、税费、换汇和频繁交易成本。
- **订单与产品规则**：理解申购、赎回、限价、市价、到账和清算时间。
- **记录与可追溯**：保留决策日期、来源、金额和理由。
- **行为复盘**：识别追涨杀跌、损失厌恶、确认偏误、过度自信和从众。

## 工具技能

- 同花顺内的公告、财务、基金、指数和自选信息检索
- 表格记录、基础公式、收益率与回撤计算
- 简单脚本的数据清洗和可视化
- 版本化保存研究笔记，避免修改后失去历史判断

## 学习状态定义

- `未开始`：知道名称，但没有实际练习。
- `学习中`：正在阅读或跟随课程练习。
- `可解释`：能用自己的话说明概念和局限。
- `可复核`：完成过一次有来源、有计算、有结论的练习。
- `可执行`：能在月度流程中稳定使用，且知道何时不该使用。
