# 动效实验室：仿 Lusion 栏目

> 日期：2026-07-18  
> 路由：`/lab` 内部栏目  
> 当前状态：01 / 零件力场第一版  
> 发布：GitHub `main` 触发 Cloudflare 自动部署

## 目标

在不复制 Lusion 原站素材、品牌排版和完整页面的前提下，学习其实时 3D 交互机制。第一版只验证“零件向中心聚合、鼠标碰撞、点击冲击”是否能在 Sakura1Tap 中形成稳定且有辨识度的体验。

## 当前实现

- 动效实验室保留原有四窗口放映场，并新增明确的“仿 Lusion”栏目入口。
- 栏目使用独立动态分包；只有用户进入后才加载 Three.js 实验组件。
- 使用 26 个桌面端程序化零件，由盒体、环体、圆柱、多面体和锥体组合。
- 每个零件包含位置、速度、角速度和近似碰撞半径。
- 每帧施加中心吸引、轻微旋转流场、阻尼、边界回弹和零件间碰撞。
- 鼠标映射到 Three.js 世界平面，附近零件获得排斥冲量；点击释放一次扩大冲击。
- 使用 RoomEnvironment、PMREM、物理材质和三组灯光生成金属、陶瓷和亮面塑料质感，不依赖新增图片或 HDR 素材。
- “重新散开”使用固定种子伪随机重新布置，便于复现与调试。

## 性能与兼容边界

- 桌面端 26 个零件，窄屏 14 个，reduced-motion 10 个。
- DPR 桌面上限 1.5，窄屏上限 1.15。
- 页面不可见时暂停物理与渲染更新。
- 离开栏目时移除事件、停止 RAF，并释放 Geometry、Material、PMREM 和 Renderer。
- WebGL 创建失败或 context lost 时显示明确回退界面，不让栏目停在空白页。
- 第一版不引入 Rapier WASM；当前轻量碰撞用于验证手感。后续只有在复杂模型碰撞确有必要时才升级物理引擎。

## 设计边界

- 可学习：单 Canvas、中心吸引力、指针碰撞、材质表现、DOM 与 WebGL 分层。
- 不复制：Lusion 原模型、视频、文案、Logo、完整页面布局和生产代码。
- 当前栏目使用 Lusion v3 的蓝白高对比作为研究标识，同时加入 Sakura1Tap 的品红色冲击反馈。
