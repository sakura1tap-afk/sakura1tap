# 动效实验室：仿 Lusion 栏目

> 日期：2026-07-18  
> 路由：`/lab` 内部栏目  
> 当前状态：01 / 零件力场 V2

## 目标

在不复制 Lusion 原站素材、品牌排版和完整页面的前提下，学习其实时 3D 交互机制。V2 将第一版的视觉验证升级为真正的刚体实验，重点解决零件数量偏少、碰撞轻飘、缺少重量以及点击反馈单一的问题。

## 当前实现

- 动效实验室保留原有四窗口放映场，并新增明确的“仿 Lusion”栏目入口。
- 栏目使用独立动态分包；只有用户进入后才加载 Three.js 实验组件。
- 物理层由手写位置积分升级为 Rapier 3D；Three.js 只负责场景、材质、光照与渲染同步。
- 桌面高性能档使用 56 个程序化零件，低性能桌面 40 个，窄屏 28 个，reduced-motion 18 个。
- 几何种类扩展到 10 类：长条、圆环、圆柱、多面体、锥体、胶囊、四棱锥、扭结和齿轮等。
- 为零件配置圆角盒、圆柱、锥体、凸包和多球复合碰撞体；圆环和扭结不再退化为单一碰撞球。
- 每个刚体具有独立质量、惯性、摩擦、弹性、线性阻尼、角阻尼、弱世界重力和连续碰撞检测策略。
- 物理以固定 60Hz 时间步运行，单帧最多追赶 3 次，避免不同刷新率造成不同的碰撞手感。
- 力场采用“双重引力”：弱向下世界重力提供重量，距离相关的中心引力维持悬浮构图，并保留低强度旋转流场与 Z 轴收束。
- 鼠标靠近产生连续排斥；点击零件切换主题颜色并增加角冲量；按住零件以阻尼弹簧力拖动；点击空白释放范围冲击。
- 使用 RoomEnvironment、PMREM、物理材质和三组灯光生成金属、陶瓷和亮面塑料质感，不依赖新增图片或 HDR 素材。
- “重新散开”使用固定种子伪随机重新布置，便于复现与调试。

## 性能与兼容边界

- 零件数量会根据视口、`hardwareConcurrency`、`deviceMemory` 和 reduced-motion 自动分档。
- DPR 桌面上限 1.45，窄屏上限 1.12；连续 4 秒低于 44 FPS 时自动降到 DPR 1。
- Rapier 与栏目一起动态加载；首页和功能空间不会下载物理引擎，只有进入“仿 Lusion”后才产生额外网络与 WASM 成本。
- 独立生产构建验证中，Rapier compat 分包约 830KB gzip，实验渲染分包约 138KB gzip；这是获得真实刚体碰撞的明确成本，需继续观察首次进入等待时间。
- 页面不可见时暂停物理与渲染更新。
- 离开栏目时移除事件、停止 RAF，并释放 Rapier World、Geometry、Material、PMREM 和 Renderer。
- WebGL 创建失败或 context lost 时显示明确回退界面，不让栏目停在空白页。

## 设计边界

- 可学习：单 Canvas、中心吸引力、指针碰撞、材质表现、DOM 与 WebGL 分层。
- 不复制：Lusion 原模型、视频、文案、Logo、完整页面布局和生产代码。
- 当前栏目使用 Lusion v3 的蓝白高对比作为研究标识，同时加入 Sakura1Tap 的品红色冲击反馈。

## 下一步

1. 线上观察 56 刚体档的帧率、Rapier 初始化时间与 WebGL context 稳定性。
2. 根据真实手感调整世界重力、中心引力、拖拽弹簧刚度和碰撞弹性；本阶段不继续增加新功能。
3. 若程序化形状已经稳定，再将其中少量几何升级为原创低面数“樱花机械零件”GLB。
4. 零件力场稳定后再开始 02 / 滚动航行，避免两个实验并行扩张。
