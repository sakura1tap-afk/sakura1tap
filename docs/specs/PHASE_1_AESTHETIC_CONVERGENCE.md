# Phase 1：中文暗色视觉收口

> 状态：进行中  
> 首轮实现：2026-07-15  
> 范围：Boot / Live2D Entry / Cinematic Home / Metadata / Docs

## 1. 目标

在不推翻现有 WebGL、GSAP 五幕叙事、Live2D 舞台和既有路由的前提下，将入口与主页统一为克制的中文暗色个人空间。

本阶段解决四个直接问题：

1. 入口按钮信息过多、尺寸偏大且移动端容易显示不完整。
2. 英文大标题占据过多画面，和中文网站定位不一致。
3. Boot、静态 fallback 与 WebGL 首帧之间存在色调跳变和浅色底暴露风险。
4. 按钮、光标、脉冲和持续动画同时抢夺注意力。

## 2. 设计锁定

- 品牌名 `SAKURA1TAP` 保留英文，作为角落签名存在。
- 操作、导航、状态和主要说明改为中文。
- 视觉比例采用冷黑主体、雾面白信息与少量暖金反馈。
- 一屏只保留一个主要互动，不继续叠加新 shader 或新 3D 素材。
- 中文正文优先使用稳定的系统无衬线字体；展示性衬线仅用于少量强调文字。
- Live2D 本轮继续保留在入口，但降低按钮与文案对角色构图的干扰；是否改为 AI 助手留到下一阶段。

## 3. 首轮实现

### 3.1 Boot

- 将加载与错误状态改为中文。
- Boot、Entry 和 Home 共用深色视觉基底。
- 保留原始高质量背景图，不通过降低素材清晰度换取统一感。

### 3.2 Entry

- 删除入口中央的英文诗意文案。
- 将按钮收敛为单行中文状态：`准备中`、`进入`、`正在进入`。
- 按钮改为底部居中的小型胶囊玻璃控件。
- 磁吸范围从强位移降低为 4px × 3px，按压缩放统一为 0.98。
- 删除独立暖色光球和持续脉冲，只保留一次性扫光、轻描边与箭头位移。

### 3.3 Cinematic Home

- 五幕结构保留，章节改为：首页、互动、功能、片段、继续。
- 英文展示文案改为简短中文，不进行生硬的逐字翻译。
- 主标题上限从约 145px 降至 88px；其他章节标题统一压至 62–74px 以内。
- 提升过小辅助文字的可读性，压缩极端字号差距。
- 自定义光标从 54–90px 收敛到 34–56px，并删除跟随文字。
- 功能入口使用直接说明，保留 `/play`、`/play/blackout` 与 `/lab`。

### 3.4 Canvas handoff

- WebGL 创建后立即使用深色不透明颜色清屏。
- 静态 fallback 始终保留在 Canvas 后方，直到有效纹理完成首帧绘制。
- 静态图增加统一深色遮罩，减少浅色素材在加载阶段暴露。
- shader 进行轻微冷色校正，使静态图、动态画面与入口色调更接近。

## 4. 本阶段不做

- 不改变路由结构。
- 不移除或重写 Live2D 底层加载。
- 不新增字体二进制、模型、HDRI 或高分辨率场景素材。
- 不增加新 shader、新小游戏或 AI 后端。
- 不以降低图片质量的方式优化加载。

## 5. 验收标准

- 入口按钮在常见桌面、短屏和移动端完整可见，且只呈现一个主要动作。
- 页面从 Boot 到 Entry 再到 Home 不出现白色或米白色空画布。
- 主要导航与操作无需理解英文即可使用。
- 中文标题不使用英文式极端负字距与过紧行高。
- 主页视觉主体仍然是场景，文字不再覆盖大部分屏幕。
- `prefers-reduced-motion`、WebGL fallback、`/play`、`/play/blackout`、`/lab` 不被破坏。
- 完整仓库环境运行 `npm run build`，并在桌面与移动端进行视觉复核。
