# Entry Moonlit Refinement：入口幽静月色收口

> 日期：2026-07-16  
> 范围：入口背景氛围与图像呈现  
> 状态：已实现

## 问题判断

- 左上方黄色光晕来自旧版 `.live2d-entry::before` 全局伪元素，并非当前背景图本身。
- 旧伪元素仍覆盖在 `CinematicEntry` 上，造成新旧视觉语言冲突。
- 桌面背景资产为 2880×1620，尺寸足以覆盖常见 1080p 视口。
- 文件约 176KB，压缩较强；同时旧样式的整体降亮与 1.5% 放大进一步削弱了细节感。

## 本次处理

- 在 `.live2d-entry.cinematic-entry` 范围明确关闭旧版 `::before` 与 `::after`。
- 背景氛围改为低饱和深青灰，仅在月亮方向保留极弱冷色环境光。
- 品牌竖线、按钮边缘、箭头、悬停与进入转场由暖金色改为低饱和月光蓝灰。
- 背景静态放大从 1.5% 降至 0.4%，减少无意义插值和裁切。
- 提高中间调亮度和局部对比，同时降低饱和度，让建筑、花枝和水面细节更清楚但不变亮俗艳。
- 进入转场放大从 6.5% 收敛至 3.5%。

## 图像质量结论

- CSS 可以减少模糊来源、恢复现有细节，但无法生成原图不存在的纹理。
- 当前 2880×1620 尺寸不需要普通插值放大；简单扩成 4K 只会增加文件体积。
- 真正提升上限应从同构图的高质量母版重新导出，目标建议为 3840×2160 AVIF/WebP，并保留现有 2880×1620 作为兼容回退。
- 新母版上线前优先保留本次渲染优化，避免用锐化滤镜放大压缩噪点。

## 验收标准

- 入口不再出现左上角黄色光晕。
- 整体保持幽暗、冷静、月夜感，画面没有明显蓝色霓虹倾向。
- 背景主体细节比旧版更清晰，左侧仍为 Live2D 和品牌保留安静暗区。
- 按钮仍可辨识，但不再形成暖色视觉焦点。
