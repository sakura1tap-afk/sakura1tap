# Reaction Test：五次平均反应时间

> 日期：2026-07-16  
> 路由：`/play/reaction`  
> 状态：第一版实现

## 测试规则

- 每组测试包含 5 次有效反应。
- 每次先显示红色等待画面，再在随机时间切换为绿色。
- 随机等待范围为 1.2–8 秒，任何一次都不得超过 8 秒。
- 绿色出现时使用 `performance.now()` 记录高精度起点。
- 用户按下鼠标、触控屏或空格时记录反应耗时。
- 红色阶段提前操作判定为抢跑，该次不计入五次结果。
- 完成 5 次后将结果相加并四舍五入计算平均毫秒数。

## 状态机

1. `idle`：等待开始。
2. `waiting`：红色，随机计时器运行。
3. `ready`：绿色，等待用户操作。
4. `result`：显示单次结果，点击进入下一次。
5. `false-start`：抢跑，不计分，点击重试当前次数。
6. `complete`：显示五次结果和平均值，可重新测试。

## 交互与界面

- 整个测试区域都是操作面，不使用狭小按钮接收关键反应。
- 顶部显示五次测试进度，底部显示随机范围、输入方式和已有记录。
- 红色等待状态不显示倒计时或可预测进度动画。
- 支持鼠标、触控、Enter 与空格。
- 页面离开或重新测试时清理未完成的随机计时器。
