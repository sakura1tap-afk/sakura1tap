# Motion Lab：窗口即界面

> 日期：2026-07-16  
> 路由：`/lab`  
> 状态：第一版实现

## 目标

将旧版 3D installation 实验室替换为独立、轻量、以真实视频窗口为核心的动效放映场。窗口不再是 3D 场景里的装饰物，而是内容、入口、播放器与导航本身。

## 设计规则

- 不设置独立播放按钮；点击窗口完成聚焦、播放与暂停。
- 默认四窗口错落构图，聚焦后窗口移动到中心并放大。
- 未聚焦窗口只做封面预览和轻量空间视差。
- 空白区域支持拖动窗口阵列，桌面端使用自定义光标反馈。
- 只保留品牌、路由返回、窗口名称、状态与进度等功能信息。
- 使用真实 `<video>`、CSS 3D 与浏览器合成层，不继续使用 Three.js `VideoTexture`。
- 移动端采用 2×2 概览与单窗口聚焦；减少并行动画和无意义装饰。
- 支持 Escape、左右方向键与 `prefers-reduced-motion`。

## 第一版内容

- 复用四段现有 MP4，命名为流光、折射、回声、余像。
- 入口动画、窗口悬浮层次、扫描光、回声边框和聚焦脉冲。
- 悬停预览；点击聚焦后播放，再次点击切换暂停。
- 聚焦时显示真实播放进度；“概览”回到四窗口布局。
- 空白区域拖动产生带深度差的整体视差。
- 品牌按钮真正返回 Sakura1Tap 首页。
