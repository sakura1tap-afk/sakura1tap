# Function Space：可扩展模块库

> 日期：2026-07-16  
> 路由：`/play`  
> 状态：第一版实现

## 目标

将旧版 Play Toolbox 从单个游戏介绍页改造成可长期容纳游戏、工具和交互实验的统一功能空间。页面优先解决分区、检索、状态和扩展问题，不追求复杂视觉技术。

## 信息架构

- 顶部：返回 Sakura1Tap、页面名称、可用模块数量。
- 控制区：全文搜索与全部 / 游戏 / 工具 / 实验分类筛选。
- 内容区：按游戏、工具、实验分区，每个分区显示数量。
- 模块卡片：固定展示分类、状态、名称、简短说明、标签和入口。
- 状态统一为：可用、制作中、规划中。

## 第一版模块

### 游戏

- 反应时间测试：可用，5 次有效测试后计算平均值。
- 反应矩阵：制作中。

### 工具

- 颜色工坊：规划中。
- 图片工作台：规划中。
- JSON Lens：规划中。

### 实验

## 设计规则

- 不再使用一块巨大的介绍区和重复模式列表。
- 说明文案限制为单句，只解释模块用途。
- 可用模块提供明确“打开”动作；未完成模块不伪造入口。
- 数据集中在模块配置中，增加新功能时不需要重写页面结构。
- 桌面三列、平板两列、移动端单列；特色模块可占两列但不破坏分区。
- 保持 Sakura1Tap 的深色、雾白和少量暖金系统，不引入新的 3D 或重型依赖。
